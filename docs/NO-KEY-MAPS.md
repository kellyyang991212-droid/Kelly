# 免金鑰地圖搜尋與收藏

目前採用 Google Maps 官方搜尋／導航連結，不需要 Google Cloud、帳單、Places 金鑰或本機搜尋代理。

## 新增行程

1. 進入旅行 → 新增行程。
2. 在「Google Maps 搜尋關鍵字」輸入中文，例如「清水寺」或「親子景點」。預設搭配旅行目的地，也可自行輸入城市。
3. 點「到 Google Maps 搜尋景點」，開啟 Google Maps App 或網頁查看真實結果。
4. 返回旅伴手帳，填入景點名稱、地址／區域；可從 Google Maps 的「分享 → 複製連結」貼上分享連結。
5. 確認行程名稱、日期、時間及備註，加入行程。
6. 行程的「地圖查詢」優先開啟已保存的分享連結；未填分享連結時使用名稱與地址搜尋。「路線規劃」使用名稱與地址作為目的地。

## 美食

1. 旅行 → 美食 → 搜尋美食。
2. 輸入「拉麵」「咖啡」等字詞，到 Google Maps 搜尋目的地附近美食。
3. 「到 Google Maps 找目前附近美食」會把附近查詢交給 Google Maps；位置與定位權限由 Google Maps 自行判斷及請求。本 App 不讀取目前位置。
4. 回 App 填店家名稱、地址及可選的分享連結，點「收藏這間店到旅行」。
5. 在美食卡片可查看原地圖、加入行程、記錄餐費。相同分享連結或相同名稱＋地址的手動收藏會去重。

## 清楚區分搜尋與保存

- 真實搜尋結果、評價與營業資訊顯示在 Google Maps；App 不抓取或自動帶回這些內容。
- App 只保存你自行填寫的名稱、地址、備註與分享連結。不解析短網址、不擷取網頁、不假造店家建議。
- 分享連結僅接受 HTTPS 的 Google Maps 官方網址；無效連結會阻止儲存，避免遺失或誤存。
- 原有京都示範旅行、虛構餐廳與示意照片保留並標示。新保存的店家標示「自行填寫」，照片仍是示意圖。
- 未儲存表單留在目前 App 記憶體；切回可繼續，若 App 被系統終止則可能遺失。按儲存後才寫入本機。
- 登入、邀請朋友、多人聊天與雲端同步仍未串接，不會因地圖免金鑰功能而啟用。

## 啟動

```sh
pnpm install
pnpm web
```

不需要執行 `pnpm places:server`，也不用填 `.env` 或 `.env.places`。舊的 Places API 程式與設定文件保留作未啟用的參考，現在的 App 畫面不會呼叫它們。

依據：[Google Maps URLs 官方文件](https://developers.google.com/maps/documentation/urls/get-started)。
