# 免金鑰地圖搜尋與收藏

行程景點和美食店家都可在表單內選取。外開地圖查詢、導航與附近美食搜尋採用 Google Maps 官方連結，無需 Google Cloud、帳單、Places 金鑰或本機搜尋代理。

## 新增行程

1. 進入旅行 → 新增行程。
2. 在「景點或美食關鍵字」輸入地點名稱或餐點，例如「清水」或「拉麵」。內建清單會優先顯示旅行目的地的符合項目。
3. 內建清單找不到時會自動線上搜尋。點選結果後會帶入名稱和地址或地區。也可以點「線上搜尋地點」查找更多結果。
4. 可手動修改帶入的資料，也可到 Google Maps 查詢後回來填寫。分享連結可從 Google Maps 的「分享 → 複製連結」取得。
5. 確認行程名稱、日期、時間及備註，加入行程。
6. 行程的「地圖查詢」優先開啟已保存的分享連結；未填分享連結時使用名稱與地址搜尋。「路線規劃」使用名稱與地址作為目的地。

## 美食

1. 旅行 → 美食 → 搜尋美食。
2. 輸入「拉麵」「咖啡」等字詞並點選店家，表單會帶入店名和地址或地區。按「線上搜尋店家」可找到更多店家。
3. 可手動修改資料及貼上分享連結，再按「收藏這間店到旅行」。相同分享連結或相同名稱＋地址的收藏會去重。
4. 在美食卡片可查看原地圖、加入行程、記錄餐費。
5. 「到 Google Maps 找目前附近美食」會將附近查詢交給 Google Maps。定位權限由 Google Maps 請求。

## 清楚區分搜尋與保存

- 內建清單可離線使用。找不到內建地點且輸入至少兩個字元時，會自動把關鍵字與選擇搭配的目的地送到 Photon（OpenStreetMap 資料）。若服務暫時無法使用，仍可手動填寫。
- App 保存選取或自行填寫的名稱、地址或地區、備註與分享連結。外開 Google Maps 可查看評價與營業資訊。
- 分享連結僅接受 HTTPS 的 Google Maps 官方網址；無效連結會阻止儲存，避免遺失或誤存。
- 原有京都示範旅行的虛構餐廳會標示。新收藏的店家也使用示意照片。
- 未儲存表單留在目前 App 記憶體；切回可繼續，若 App 被系統終止則可能遺失。按儲存後才寫入本機。
- 登入、邀請朋友、多人聊天與雲端同步仍未串接，不會因地圖免金鑰功能而啟用。

## 啟動

```sh
pnpm install
pnpm web
```

不需要執行 `pnpm places:server`，也不用填 `.env` 或 `.env.places`。舊的 Places API 程式與設定文件保留作未啟用的參考，現在的 App 畫面不會呼叫它們。

依據：[Google Maps URLs 官方文件](https://developers.google.com/maps/documentation/urls/get-started)。
