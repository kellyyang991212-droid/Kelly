# 旅伴手帳｜後續開發清單

目前階段：本機可操作畫面原型。以下均尚未串接或實作，不應視為已具備正式服務能力。

## 第一階段：帳號、共同空間與資料基礎

- [ ] Supabase Auth：確認 Email OTP／Apple／Google 登入方式，登入復原、登出、撤銷裝置與帳號刪除；token 放安全儲存，不放一般 AsyncStorage。
- [ ] 旅行資料表：`trips`、`trip_members`、`invitations`、`itinerary_items`、`places`、`expenses`、`expense_shares`、`photos`、`messages`。每筆都綁定 trip_id、建立者、UTC 時間、版本與刪除狀態；旅行另存 IANA 時區與各事件在地時間。
- [ ] 權限矩陣：擁有者可邀請、移除成員及管理分享；編輯者可編排行程與新增紀錄；檢視者唯讀。帳目修改應有稽核紀錄；最後一位擁有者退出前需移轉權限。
- [ ] Postgres RLS 與 Storage policy：所有查詢與 mutation 都驗證旅行成員，不能只依賴前端隱藏按鈕。service-role key 不得放 App。
- [ ] 邀請：一次性或有期限 token、接受前預覽、重複加入防護、撤銷與成員退出後立即停止存取；加入時不擅自分享全部歷史資料。
- [ ] 雲端儲存：schema migrations、索引、外鍵、交易、備份與還原演練；區分本機草稿與已同步，避免誤覆蓋雲端。

驗收：兩個帳號可加入同一旅行；第三個非成員帳號無法以直接 API 讀寫行程、帳目或照片。權限撤銷後既有 session 也無法繼續取用受限資料。

## 第二階段：多人共同編輯與旅程紀錄

- [ ] Supabase Realtime 訂閱依 trip 隔離；處理重複／亂序事件、重連後補抓資料、未讀計數及活動紀錄。
- [ ] 共同編輯採 version 條件更新；同欄位衝突顯示「自己的版本／旅伴版本」比較，不靜默覆蓋。不同欄位可合併，但仍保留稽核。
- [ ] 離線操作佇列：mutation UUID 保證冪等，樂觀 UI 失敗可回復、重試；移除成員時清除其離線隊列與快取。
- [ ] 行程編輯、排序、移動日期、刪除及復原；以穩定排序鍵處理同時拖曳；預約資訊、旅程筆記及完成狀態。
- [ ] 真實美食收藏：自訂店家、地圖搜尋、網址、地址、備註、去重與加入行程；商家資訊標示來源與更新時間。
- [ ] 手機 App 內地點搜尋：目前已提供新增行程的外部 Google Maps 查詢與路線規劃；後續串接 Places 地點搜尋／選點，帶回 place ID、確認地址與座標。設定 API key 限制、計費配額、來源標示與地點資料保存規則；雙平台測試有／無 Google Maps App 的開啟與返回。
- [ ] 聊天：真實訊息送達／失敗狀態、分頁、已讀、離線補送與訊息刪除策略。

驗收：兩人同時更改同一行程會看到可處理的衝突；離線新增後重連只新增一次；刪除與編輯競爭不造成資料重生。

## 第三階段：分帳精度與核銷

- [ ] 金額統一採幣別最小單位整數；JPY 0 位、TWD／USD 規則由產品決定，避免浮點誤差；資料庫加總一致性約束。
- [ ] 均分尾數正式規則需取得產品共識。原型採固定 ID 排序；正式版儲存每人的分攤結果與演算法版本，成員改名／退出不重算歷史分攤。
- [ ] 不均分、比例、指定金額、付款人不參與分攤、退款／負向調整、零元與超額限制；所有分攤必須等於總額。
- [ ] 多幣別依幣別各自結算；若換算，儲存匯率、日期、來源及精度，不混加不同幣別；匯率更動不得無提示改變歷史結果。
- [ ] 實際補款以雙方確認與不可變核銷紀錄處理，支出修改／撤銷後要重算或更正；對帳與 CSV 匯出。
- [ ] 測試 1 元多人均分、極大值、選取順序、重新加入、刪除付款人、重複提交、跨幣別與退款。

驗收：每筆支出 shares 總和等於 amount；所有餘額加總為 0；完成建議轉帳後餘額全為 0；伺服器拒絕篡改金額與不合法成員。

## 第四階段：共同相簿與分享範圍

- [ ] Supabase Storage 私有 bucket，短效簽名 URL；壓縮縮圖、檔案大小／格式驗證、進度、取消、上傳重試與去重。
- [ ] 相片選取／相機權限只在需要時請求，拒絕後仍可使用其他分頁；處理 HEIC、旋轉方向及影片範圍。
- [ ] EXIF／GPS 預設移除，照片可見成員、批次下載、留言、作者刪除、旅行刪除後的檔案清除與保存政策。
- [ ] 分享預設僅旅伴；分開設定行程、文字、照片、帳目。公開摘要不得意外包含帳目、聊天、精確住宿位置或相片定位。
- [ ] 連結 token 綁定允許範圍、到期、撤銷、密碼或受邀帳號；URL 不包含登入憑證；分享前提供實際內容預覽。
- [ ] OS share sheet、deep link、未安裝 App 的唯讀頁；撤銷後快取也應有期限。

驗收：被撤銷連結與簽名照片 URL 到期後不可讀；行程唯讀分享無法取到聊天、帳目與未勾選照片。

## 第五階段：LiveKit 即時語音

- [ ] 透過受保護的伺服器／Supabase Edge Function 驗證 JWT 與 trip membership，再簽發短效 LiveKit token；API secret 僅留伺服器。
- [ ] 每趟旅行隔離 room；角色與 publish／subscribe 權限、移除成員、並發上限、費用與流量限制。
- [ ] 需 development build 與原生音訊套件相容性確認；不可將 Expo Go 視為正式語音驗證環境。
- [ ] 麥克風權限、音訊路由（聽筒／喇叭／藍牙）、加入／離開、靜音、說話指示及網路品質；不預設錄音。
- [ ] 來電與推播、背景／鎖定畫面、iOS 音訊中斷、Android foreground service、電話插入、斷線重連、token 更新。
- [ ] 成員離開與旅行刪除立即失效；記錄必要診斷但不儲存原始語音，明確顯示通話狀態。

驗收：兩台真機不同網路可通話；拒絕麥克風、切藍牙、斷網再恢復、App 進背景及成員被移除均有可預期行為。

## 第六階段：iPhone／Android 發行前測試

- [ ] iPhone 小螢幕／大螢幕／瀏海與 Android 小螢幕、打孔、手勢與三鍵導覽；安全區域與底部按鈕可達。
- [ ] iOS／Android 真機原生 build；記錄裝置、OS、SDK、build number；檢查升級與資料遷移。
- [ ] 大字體、VoiceOver／TalkBack、色彩對比、觸控至少 44 pt／48 dp、鍵盤遮擋、橫向／平板行為。
- [ ] 日期跨時區、夏令時間、跨年，金額格式、繁中輸入法、照片上傳中斷與記憶體壓力。
- [ ] 弱網、飛航、連續點擊、App 被系統回收、磁碟滿、token 過期、429／500 與請求 timeout。
- [ ] 登入→邀請→共同編輯→支出→相片→聊天→語音→分享→撤銷完整端到端測試。
- [ ] Crash／效能監測、資料保存與刪除政策、隱私揭露、商店截圖、TestFlight／Play 內部測試與回報管道。

正式發布條件：以上權限隔離、金額守恆、同步衝突與雙平台真機情境通過；不得僅憑 Web 原型成功就宣稱支援原生全部功能。
